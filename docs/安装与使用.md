# 安装与使用

## 1. 选对 jar

看你玩的 Minecraft 版本和加载器，**只放一个**：

| Minecraft | Fabric | Forge / NeoForge |
| --- | --- | --- |
| 1.20.1 | `DangoMusic-1.5.1-qqmusic+1.20.1-fabric.jar` | `…+1.20.1-forge.jar` |
| 1.21.1 | `…+1.21.1-fabric.jar` | `…+1.21.1-neoforge.jar` |
| 1.21.11 | `…+1.21.11-fabric.jar` | `…+1.21.11-neoforge.jar` |
| 26.2 | `…+26.2-fabric.jar` | `…+26.2-neoforge.jar` |
| 26.3 | `…+26.3-fabric.jar` | `…+26.3-neoforge.jar` |

环境要求（与原版一致）：

| 版本 | Java | 加载器 |
| --- | --- | --- |
| 1.20.1 | 17+ | Fabric Loader ≥0.15 / Forge 47.x |
| 1.21.1 | 21+ | Fabric Loader ≥0.15 / NeoForge 21.1 |
| 1.21.11 | 21+ | Fabric Loader ≥0.17 / NeoForge 21.11 |
| 26.2 / 26.3 | 25+ | Fabric Loader ≥0.19 / NeoForge 26.x |

Fabric 端还需要 **Fabric API**；Forge / NeoForge 端不需要。

## 2. 放进 mods

把 jar 放进 `.minecraft/mods/`。

- 如果之前装过原版（网易云版）DangoMusic，**先删掉**：两者 `id` 都是 `dangomusic`，同时放会冲突。
- 本改版可以覆盖安装到已有存档，不需要开新世界（它不影响世界数据）。

## 3. 打开播放器

进游戏按 `M`。

**如果按 M 没反应：**

1. 检查是不是还留着原版 jar（冲突时游戏通常会报 `Duplicate mod` 或只加载其中一个）。
2. 检查 `config/dangomusic/config.json` 里该模块是否 `"enabled": true`。
   注意模块名必须是 `NeteaseMusic`，这是配置的键；不要手改成别的名字，否则配置失效、模块回到默认关闭。

## 4. 登录 QQ 音乐

播放器左下角 → `Log in to QQ Music` → 弹出二维码 → **手机 QQ 扫码** → 手机上点确认。

- 成功后按钮位置显示头像与昵称，凭据写入 `config/dangomusic/qqmusic_cookie.txt`。
- 有效期约 3 天。过期后界面上会重新显示登录按钮，再扫一次即可。
- 二维码过期可以点 `Refresh QR`。

会员歌、无损音质取决于你自己的 QQ 音乐账号，本模组不提供任何绕过。

## 5. 常见现象

| 现象 | 原因 |
| --- | --- |
| 能进界面但点歌没声音 | 未登录 / 登录态过期 / 该曲需要会员 |
| 歌词一直空白 | 该曲无歌词；或未登录（部分歌词接口需要登录态） |
| 按 M 无反应 | 原版 jar 冲突，或模块被配置成 disabled |
| 一起听建房失败 | 见 [一起听.md](一起听.md)，通常是代理或 Firebase 配置问题 |
