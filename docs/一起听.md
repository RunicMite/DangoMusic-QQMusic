# 一起听（Listen Together）

一起听让房间成员同步听同一首歌。实现方式：用一个 Firebase Realtime Database 当"公告板"。
**房间里所有人必须连同一个 Firebase 项目**——房间码只在本项目内可见，不同项目之间互相看不到房间。

---

## 一、准备自己的 Firebase 项目（房主做一次即可）

### 1. 建项目与数据库

1. 打开 <https://console.firebase.google.com>（国内需要代理），新建项目。
2. `Build` → `Realtime Database` → `创建数据库`。
   位置建议选 `asia-southeast1`（新加坡），国内延迟最低。安全规则先随便选，下一步会覆盖。
3. `Authentication` → `开始使用` → `Sign-in method` → 启用 **Anonymous**（匿名）→ 保存。
   模组不需要 Google 账号，每个客户端会匿名注册一个 uid。

### 2. 写安全规则

`Realtime Database` → `规则`，替换成：

```json
{
  "rules": {
    "rooms": {
      "$code": {
        ".read": "auth != null",
        ".write": "auth != null"
      }
    },
    "clock": {
      "$uid": {
        ".read": "auth != null",
        ".write": "auth != null",
        ".validate": "auth.uid === $uid"
      }
    }
  }
}
```

说明：`rooms` 是房间数据，`clock/<uid>` 是用来对齐客户端时钟的（写 `.sv: timestamp` 让服务器填时间）。
未登录访问会返回 `401 Permission denied`，这是正常的。

### 3. 抄两个值

- `项目设置` → `常规` → `Web API Key`（形如 `AIzaSy...`）
- `Realtime Database` 页面顶部的 URL（形如 `https://xxx-default-rtdb.asia-southeast1.firebasedatabase.app`）

### 4. 写进配置文件

放到 `.minecraft/config/dangomusic/firebase.properties`：

```properties
apiKey=你的 Web API Key
databaseUrl=你的数据库 URL

# 国内直连不了 Google，需要代理
proxy=127.0.0.1:7890
proxyType=http

connectTimeout=10000
readTimeout=20000
pollMs=3000
```

- `proxy`：Clash / FlClash 一般 `7890`；V2Ray 常见 http `10809`。**用 TUN 模式或全局代理就把这行删掉**。
- `pollMs`：拉取间隔，默认 3000 ms。网络差可以调大到 5000。

> ⚠️ 这个文件不要提交进 Git、不要公开发给别人。apiKey 就是数据库的钥匙，
> 泄露后任何人都能读写你的库并把免费额度刷完（100 并发连接 / 1 GB 存储 / 每月 10 GB 下载）。
> 想让朋友进你的房间，就让他们用同一份 apiKey + databaseUrl，但只私下发。

---

## 二、使用

1. 播放器里切到 `Listen Together` 页。
2. 建房：`Create a room` → 得到一个 5 位房间码（如 `AB3KM`）→ 发给朋友。
3. 加入：同一页输入房间码 → `Join`。
4. 房主控制播放/暂停/切歌，其他人自动跟随（含进度漂移纠正）。

房主每 1.5 秒发一次心跳，11 分钟没有心跳（退游戏、掉线）房间会被自动回收。

房间里每个人用**各自的 QQ 音乐账号**取播放地址，所以会员歌需要各自都有会员——
这一点与原版设计一致，不是 bug。

## 三、排错

先看 `.minecraft/logs/latest.log`，搜 `Firebase`。

| 日志 | 含义 | 处理 |
| --- | --- | --- |
| `Firebase anonymous login ok, uid=...` | 一切正常 | — |
| `Firebase ... failed: ConnectException` / `timed out` | 连不上 Firebase | 代理没开 / 端口写错 / 代理没走全局 |
| `401 Permission denied` | 安全规则不对 | 检查规则是否要求 `auth != null`，以及匿名登录是否启用 |
| `OPERATION_NOT_ALLOWED` | 项目的匿名登录没开 | `Authentication` → 启用 Anonymous |
| `CONFIGURATION_NOT_FOUND` | databaseUrl 写错 | 从控制台重新复制 |
| 建房成功但朋友进不去 | 两边不是同一个项目 | 对比 `firebase.properties` 的 apiKey / databaseUrl |

自检思路（不依赖游戏）：把 `firebase.properties` 里的代理设好，确保浏览器能打开
`https://<你的数据库域名>/.json?auth=<随便>`, 若返回 401 而不是超时，说明网络链路是通的。
